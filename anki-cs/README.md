# 数据库基础 Anki 卡片库

为具备计算机基础、准备 C++ 后端、数据库内核及分布式存储岗位的学习者提供中文主动回忆材料，配合 FSRS 长期复习。判断标准是：半年后是否值得用 10～30 秒再回忆一次。先理解资料，再使用卡片巩固；卡片不替代系统学习。

## 阅读入口与范围

- [知识地图](knowledge-map.md)：知识范围、优先级、覆盖状态、卡片与本地来源的对应关系。
- [审查报告](review-report.md)：实际统计、核查依据、资料缺口及限制。
- 技术基线为 MySQL 8.0 + InnoDB、Redis 7.x；具体隔离级别、版本和配置以题干为准。
- 原始资料位于 `../CS-Base/mysql/`、`../CS-Base/redis/`，保持只读。

```text
anki-cs/
├── mysql/              # 每个 Markdown 文件一张 MySQL 卡片
├── redis/              # 每个 Markdown 文件一张 Redis 卡片
├── knowledge-map.md    # 知识规划与进度
├── README.md
├── review-report.md
└── validate.py         # 轻量格式、引用和统计检查
```

## 卡片格式与评分

每个文件包含 YAML Front Matter 和依次出现的三个一级标题：`# Question`、`# Answer`、`# Extra`。前两节非空；Extra 可以为空。必填元数据为 `id`、`domain`、`topic`、`priority`、`type`、`tags`、`sources`；tags、sources 为非空字符串列表，来源路径以工作区根目录为基准。

示例见 [B+ 树扇出](mysql/mysql-index-bptree-fanout.md)。Question 提供独立上下文；Answer 是最小评分依据；Extra 放条件解释、例子和核验链接，不能藏入作答必需的信息。答案不必逐字背诵，重点判断因果、限制条件和关键步骤是否正确。

## 类型、优先级与分类

| Type | 回忆目标 |
|---|---|
| concept | 精确定义；只在有独立价值时使用 |
| mechanism | 执行机制、原因和因果链 |
| comparison | 易混概念的关键差异 |
| tradeoff | 性能、资源与可靠性权衡 |
| application | 场景推理与故障分析 |
| synthesis | 少量端到端流程，以步骤和关键判据评分 |

P0 是基础机制和关键工程知识；P1 是选择性保留的重要应用或实现细节；P2 通常仅在地图中记录并跳过。本版不以数量为配额，不要求六种类型都必须出现。

Topic 词表见知识地图。知识单元可以对应多张卡，知识范围也可以大于卡片范围；`covered` 仅表示该单元列出的核心目标已覆盖。未覆盖与跳过不是同一状态。

## 文件名与增量维护

文件名严格为 `<id>.md`，ID 使用全局唯一的语义化 kebab-case，如 `mysql-index-bptree-fanout`。修订措辞或事实时保留 ID；不要用随机编号、时间戳或每轮重新命名破坏身份。

新增前先检查全部已有回忆目标，按 Topic 小批处理，完成后更新知识地图。相同机制在多篇原文中出现应合并引用；不同必要角度可分别保留。不要随意删除卡片或覆盖人工修改；不确定时保留原文并在报告记录冲突。

重要技术结论需能追溯本地来源。历史实现与基线冲突时优先补查对应版本官方文档或源码，在 Extra 和报告记录补证；无法确认时保留缺口，不假装已经核验。

## 校验

在工作区根目录运行，需 Python 3.9+ 和 PyYAML（本次环境已提供）：

```shell
python3 anki-cs/validate.py
```

脚本只读卡片，检查 YAML、字段、ID、文件名、来源边界、三个标题、非空问答、完全重复、地图登记和报告中的 JSON 统计快照。它不验证技术正确性或发现所有语义重复；这些必须另行内容审查。

改动数量、类型或覆盖状态后，根据脚本实际输出同步更新报告中的统计表及 `<!-- stats -->` 后 JSON，再重新校验。初次新增卡片时报告统计不匹配会报错，这是需要维护报告的提示，不应通过跳过校验掩盖。

## 未来 Anki 字段映射

| Markdown 内容 | 建议 Anki 映射 |
|---|---|
| id | 独立稳定 ID 字段，用于查找和更新同一 Note |
| Question | 正面字段 |
| Answer | 背面核心答案 |
| Extra | 背面补充说明 |
| tags | Anki 标签 |
| domain / topic / priority / type | 独立字段或有命名空间的标签 |
| sources | 来源字段，保留相对路径与可选展示链接 |

以后同步应按 ID 更新既有 Note，保留复习历史。当前仅交付 Markdown，不含导入或同步工具，也未创建牌组、设置 FSRS 参数或实际执行 Anki 复习。
