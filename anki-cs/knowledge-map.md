# 数据库知识地图

技术基线：MySQL 8.0 + InnoDB；Redis 7.x。覆盖状态针对本行明确列出的核心记忆目标，不表示整个 Topic 已穷尽。

P0 优先制卡；P1 选择性制卡；P2 通常跳过。uncovered 尚未制卡，partial 仅覆盖部分目标，covered 核心目标已覆盖，skipped 经评估不制卡。

## 范围与分类

MySQL：query、storage、index、buffer-pool、transaction、lock、logging、replication。
Redis：data-structure、event-loop、memory、persistence、replication、sentinel、cluster、cache、engineering。

依赖主线：页组织 → B+ 树 → 访问路径；版本链与 Read View → 隔离语义 → 锁；Buffer Pool → WAL → 提交与恢复。
Redis 主线：对象编码与事件循环 → 延迟与内存管理 → 持久化 → 复制与故障转移 → 缓存一致性。
